# 建模与验证交接：用结果选择模型

推荐交给最终测试队友的是 **`oof_convex_ensemble`**。这个选择在查看 2023 年模型评分前，已经根据 2020–2022 年按时间向前验证的结果冻结。它是本次实验的强候选，**目前不能称为已证明的 SOTA**。

## 同一批比赛上的提升

下面全部使用相同的 **2,588 场 2023 年比赛**。log loss 衡量概率质量，越低越好；准确率衡量胜者猜对比例。

| 模型 | 2023 log loss ↓ | 准确率 |
| --- | ---: | ---: |
| `lr_000_C0.1` | 0.62980 | 63.37% |
| `lr_111_C0.1` | 0.63021 | 63.60% |
| `raw_elo_k32_diff` | 0.63915 | 63.37% |
| `oof_convex_ensemble` | 0.61153 | 65.07% |

相对只用排名的逻辑回归，推荐模型的 log loss 减少 **0.01826（相对变化 2.90%）**，准确率变化 **+1.70 个百分点**。确定性的“总选排名更高者”准确率为 **63.37%**，不报告概率 log loss。

对同一赛事开始日期分块、配对重抽样得到的 log-loss 改善区间是 **[0.01233, 0.02458]**。这只反映固定模型下的探索性不确定性，未计入模型搜索、不同日期之间的依赖或未来赛季变化。

## 哪些信息有帮助

以下对照是在原四组特征逻辑回归中，每次去掉一组；正变化表示删除后变差。每个组合的正则强度都只在训练年份内选择。这些是给定其余特征后的预测增量，不是因果效应。

- 去掉**近期整体状态**后，log loss 变化 +0.00053；点估计略优，尚不能据此证明稳定增益。
- 去掉**同场地战绩**后，log loss 变化 -0.00130；该信息在这组对照中没有显示增益。
- 去掉**历史交手**后，log loss 变化 +0.00035；点估计略优，尚不能据此证明稳定增益。

扩展实验还比较了多时间尺度的整体/场地 Elo、近期状态、历史经验、休赛间隔及历史发接发统计，并测试线性模型、CatBoost、直方图梯度提升和非负加权集成。扩展删组对照以 `all_history_reference` 为参照，分别重新选择正则强度；`without_elo` 只删显式 Elo 评分，仍保留用 Elo 预期胜率算出的状态残差，不能解释为删除全部 Elo 信息。具体数值见 notebook 的扩展诊断表。原八组的最佳组合相对排名基准的改善区间跨过零，因此不应把这些微小差异写成已经确定的稳定提升。

**三个选择需要区分：** 原计划八种组合按 2023 年 log loss 选中 `lr_101_C0.01`；所有已保存模型中 2023 年分数最低的是 `all_history_reference_C0.01`；推荐进入最终测试的扩展方案仍是事先冻结的 `oof_convex_ensemble`。不会因为看到验证排名而悄悄改写冻结决定。
