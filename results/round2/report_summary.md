# 第二轮优化：候选扩展与升级判定

**结论：保留上一轮冻结集成，当前推荐仍按事先定义的训练期规则确定，为 `round1_ensemble`。** 本轮新增 **37** 个候选配置，复用 **31** 个上一轮候选的逐年预测；保留全部尝试记录。

## 先看升级门槛，再看 2023

家族配置、组合权重和单模型候选先用 **2020–2021** 的向前验证预测选择，随后在 **2022** 检查是否比对应旧流程至少降低 **0.001** log loss。2022 年旧流程为 **0.60472**，新单模型为 **0.60459**，新组合为 **0.60513**。门槛决定的是拟合/集成流程，之后才用 2020–2022 的全部开发折重新拟合选择和权重。这个门槛是预先设定的实用改进要求，不等于统计显著性检验。

**2023 在上一轮已经看过，第二轮分数必须标为探索性。** 本轮没有用新的 2023 分数反复调参，但设计受上一轮结果启发，因此不能把这次 2023 当成全新的测试集。2024–2025 年最终测试仍未打开。

## 尝试了什么，什么没有奏效

- **动态实力与不确定性：** Glicko 风格的整体/场地评分，在长时间休赛后扩大不确定性；没有新增赛后信息。
- **对手校正的发接发能力：** 将历史技术表现与当时对手的能力联系起来，尝试区分自身状态与对手强弱。
- **平滑非线性与可靠性交互：** 对排名和技术能力差使用受正则约束的样条，并让历史样本量等上下文影响预测；仍强制交换球员后概率互补。
- **融合与重加权：** 比较线性、近期加权、CatBoost、直方图提升及非负权重组合。

相对上一轮最强单模型，以下候选在这次 2023 检查中没有更低的 log loss：`adjusted_linear_C0.003`（0.61112）、`fusion_recent_C0.01_h3`（0.61115）、`compact_linear_C0.1`（0.61125）、`dynamic_linear_C0.003`（0.61167）、`odd_spline_C0.003_context1_half3.0`（0.61244）、`cat2_full_d4`（0.61278）、`hist2_compact_l15`（0.61464）、`raw_pooled_glicko_adjusted_diff`（0.64133）。 这些是不同家族在独立调参后的候选比较，**不是逐组删除且其余设置完全相同的因果或消融结论**。不能因为一种融合模型变好，就断言每一种新增信息都有帮助。完整逐年 CV、家族结果和失败候选都保留在 notebook/CSV。
