# 第六轮：补入遗漏的官方历史比赛

记录日期：2026-11-27。用户要求继续探索全量 2,588 场 2023 比赛的准确率，最终 2024–2025 测试封存。本组件实现期间没有训练或评分新模型，也没有按 2023 表现选择赛事或参数。后续模型比较属于反复使用 2023 后的探索，不能据此宣称 SOTA。

## 独立假设与决定

遵循 scientific-brainstorming 的独立生成、随后审阅流程，本 agent 先提出三个方向：N1 补回官方赛事历史，N2 历史排名轨迹，N3 破发点与局胜率残差。协调者授权三者并行实现；N2 由协调者负责，N3 见[单独记录](round6_breakpoint.md)。完整候选、反证与未做方向见[本轮协议](round6_protocol.md)。

N1 的假设是：现有 Tour 评级只采用 250/500/M/G 赛事，遗漏总决赛、Davis Cup、奥运等已经发生的比赛；这些结果可能改善某些球员的潜在实力估计。这是新增历史观测，不是新增预测目标。反证是同一算法的扩充历史与原历史对照，在向前折没有稳定收益，或收益仅来自新增算法表示而非历史覆盖。

这不是“数据越多越好”的假设。国家队比赛、已经失去晋级意义的比赛与常规巡回赛的动机可能不同；新增低频球员会改变评分网络，且历史从 2006 开始截断。因此保留完全匹配的 Tour-only 银行，先固定两种更新规则，不追加学习率搜索。

## 来源与资格规则

[实现](../../scripts/extended_history_features.py)读取与既有模块相同的哈希固定年度文件，`development_entries()` 在读取前只选择 2006–2023。原 Tour 控制直接使用已发布库存；新增历史另外读取原始来源，绝不修改库存或目标集合。

新增事件必须同时满足来源级别与规范化事件名：

| 来源级别 | 接受的名称 |
| --- | --- |
| D | 名称以 `Davis Cup ` 开头 |
| A | `World Team Championship`、`ATP Cup`、`United Cup` |
| F | `Tour Finals`、`Masters Cup`、`ATP Finals` |
| O | `Beijing Olympics`、`London Olympics`、`Rio Olympics`、`Tokyo Olympics` |

名称忽略大小写并规范空白。不能只因为级别为 D 或 A 就接受。Laver Cup、NextGen/Next Gen、未知事件名均不在白名单；地毯、缺失/非正排名、缺失或相同球员 ID、退赛/弃权沿用原库存资格规则排除。常规 `best_of` 只能是 3 或 5，使用已测试的 `score_weights` 解析器核验完整比分、每盘胜负与最终胜者。短盘、抢十替代决胜盘、赛制不一致或不完整比分保守排除，不猜测改写。实际已打完的 Davis Cup dead rubber 可以进入，但不假设其竞技动机与普通比赛相同。

原 Tour 的每个 ID 必须在年度文件中唯一连接；核对球员集合、胜者方向、日期和场地。新增 ID 不得重复，也不得与原 Tour ID 冲突。2019 Washington 继续复用已发布的日期纠正。年份和真实日期核对允许次赛季前一年 12 月 25 日起的开季周；其他跨年日期拒绝。排除目标最大 T−21 以后的记录后，才读取其比赛结果。未来年度注入的字段连身份或结果转换都不执行。

全量 36,421 个开发目标的最大历史截止为 2023-10-16，实际使用 **43,998 场原 Tour + 4,291 场额外历史**：D 3,403、A 384、F 253、O 251。白名单内另有 14 场被常规完整比分检验排除；排名、退赛/比分文本、地毯的排除量分别为 961、115、377。2,292 条非白名单记录包括原始常规赛事中没有进入已发布库存的记录与表演/特殊赛事，不能把该总数误称“表演赛数量”。这些是覆盖审计，不是模型增益。

## 固定算法及论文关系

普通 Elo 期望为 `p_A = 1 / (1 + 10**((R_B-R_A)/400))`，初始 1500。两种固定更新规则是 K=32，以及经验衰减 `K_i = 250/(max(1,N_i)+5)^0.4`。后者沿用[第四轮已核对的一手方程与作者首次计数约定](round4_margin.md)：Angelini、Candila 与 De Angelis (2022)，[Weighted Elo rating for tennis match predictions](https://doi.org/10.1016/j.ejor.2021.04.011)，[作者机构接受稿](https://cris.unibo.it/bitstream/11585/821483/2/Weighted%20ELO%20rating%20predictions%20in%20tennis.pdf)。本轮不使用比分权重，比分仅用于历史资格检查；也不声称复现该论文的样本或结果。

四个银行为 Tour/扩充历史 × 固定/经验衰减 K。同一日期的所有比赛都读取日期前的评分与场数，累加全部增量后统一写快照；自适应 K 因人而异，增量不强制零和。每个银行有整体和独立场地评分；新场地从此前已知整体评分初始化，再按 `n_surface/(n_surface+20)` 向整体收缩。未来首次出现的球员不能提前产生先验或身份信息。

输出 **20 列**：四个银行各三个整体/场地/收缩评分差，共 12 列；扩充银行相对匹配 Tour 银行的整体/收缩差，共 4 列；额外历史场数的 `log1p` 差与和、两人最小额外场数、没有额外历史的人数，共 4 列。全部 `_diff` 交换变号，其余交换不变；未知球员返回中性 1500，且明确显示覆盖不足。输出 `attrs` 保存版本、参数、来源文件、事件级别/名称数量、排除原因和奇偶列名单。

## 验证与交接

API：`build_extended_history_features(targets, inventory, *, cache_dir=DEFAULT_CACHE, raw_rows=None)`，返回原索引与顺序的有限数值 DataFrame。`raw_rows` 仅供合成测试注入 `(season, raw_dict)`。

```sh
.venv/bin/python -m unittest tests.test_extended_history_features -v
```

6 个测试覆盖手算固定/自适应更新、匹配控制、白名单与比分资格、同日共同球员和新场地初始化、T−21 端点、未来/目标结果污染、多查询截止、同日排列、A/B 交换、未知球员、重复源 ID、身份/方向和封存年份保护。真实全量生成 **36,421 × 20**，耗时约 **1.84 秒**，所有数值有限，索引保持不变；未评分新 2023 模型。

仍保留原始来源完整性、球队动机差异、比赛周而非逐日时间粒度，以及历史截断等局限。既有 2007 Buenos Aires 两条同配对 RR 记录的问题不在本模块静默去重；独立来源审计负责判断，不能按模型结果改真值。匹配 Tour-only 评分为覆盖对照，主实验的整个特征块添加也包含额外表示，因此单一块增益不能全部归因于“多了 4,291 场”。
