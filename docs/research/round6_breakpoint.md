# 第六轮：历史破发点与局胜率残差

记录日期：2026-11-27。本组件属于用户授权的继续优化；原 2,588 场 2023 目标、固定 0.5 判定阈值和 T−21 历史截止不变，2024–2025 最终测试封存。实现前独立候选与决定见[本轮协议](round6_protocol.md)，本组件没有按新 2023 分数选择先验或特征。

## 假设、证据与反证

原有技术特征主要表达平均发球/接发得分率和一发、二发、ACE、双误组成。未使用的 `bpSaved`、`bpFaced`、`SvGms` 提供关键分机会和局的结果信息。假设这些聚合量可能补充平均得分率，尤其是实际保发/破发与 IID 点模型预期之间的差。

一手动机来自 Klaassen 与 Magnus (2001)，*Are Points in Tennis Independent and Identically Distributed? Evidence From a Dynamic Binary Panel Data Model*，[作者完整 PDF](https://janmagnus.nl/papers/JRM057.pdf)。论文使用 1992–1995 Wimbledon 点级数据，发现独立同分布存在偏离，同时明确强调偏离较小，IID 对许多应用仍是合理近似。其结果不能直接证明过去 BP 残差能够预测本项目赛前胜负。Klaassen 与 Magnus (2003)，*Forecasting the winner of a tennis match*，[作者 PDF](https://www.janmagnus.nl/papers/JRM065.pdf)，[DOI](https://doi.org/10.1016/S0377-2217(02)00682-3)，给出基于发球得分概率和赛制的精确概率思路。本轮只用普通优势局的固定概率作为参照，不复现论文的估计器、点级模型或实证结果。

有力的替代解释是少量机会的随机波动、对手构成、赛事环境和技术统计错误。聚合点率与局率之间的非线性也会产生残差；它们**不是已识别的心理抗压能力**。反证是在固定向前折没有稳定提升，或者仅缺失/曝光量就能解释表面收益。论文的非 IID 发现不构成 70% 准确率承诺。

## 来源与统计恒等式

[实现](../../scripts/breakpoint_features.py)只读取哈希固定的 2006–2023 Tour 年度文件，并按已发布 Tour 库存的 `match_id` 连接历史。先按季、源、目标最大截止筛选，再读取技术统计；逐条核对球员集合、日期、场地和季。原目标比赛的统计没有直接输入路径，目标胜者标签也不参与计算。

每一方发球侧读取六个数：`bpSaved`、`bpFaced`、`SvGms`、`svpt`、`1stWon`、`2ndWon`。对应计数为：

- BP 挽救分子/分母：自己 `saved/faced`；BP 兑现：对方 `(faced-saved)/faced`。
- 被破发局数：自己 `faced-saved`；保发：`(SvGms-faced+saved)/SvGms`（等价于总发球局减被破发局）。
- 破发：对方被破发局数/对方发球局数。
- 普通发球得分：`(1stWon+2ndWon)/svpt`；接发得分：对方失去的发球分/对方发球分。

所有原始计数必须有限、非负、整数；发球分和发球局大于零。还要求 saved≤faced≤全部发球分，saved≤赢下的发球分，被破发局数≤发球局数、≤失去的发球分，且赢下的发球分≤全部发球分。不可能的组合不截断修补，而将整场双方计数对称标缺失。BP 为零本身合法，不能因为没有关键分机会删掉比赛。

技术计数依据 raw 球员 ID 归属本人；`winner`/`loser` 是来源字段布局，不是模型目标编码。本模块刻意不读取库存 `a_won`；给该标签注入非数值哨兵也不改变输出。新增历史 Elo 分支与独立来源审计另外核对胜者方向，无需使技术特征依赖标签。

## 时间窗、固定收缩与 20 列输出

整体与目标同场地均使用 `[T−364, T−21]`，含两端点。每次查询从按日期累计的历史计数相减取得窗口；同日计数求和可交换，不存在“当天先看某场结果”的顺序。允许的真实日期/赛季规则与其他模块相同，实际跨到 2024 的发展年份伪装也会拒绝。

比例采用机会加权聚合，而不是逐场百分比平均。BP 保存/兑现各收缩 20 次机会，先验为 .65/.35；普通发球/接发得分各收缩 100 次，先验为 .65/.35；保发/破发各收缩 20 局，先验由普通发球 .65 的 IID 优势局概率与其补数得到。这些是固定建模假设，不是从全体年份估出的先验。

令 q=1−p，普通优势局的精确保发概率为：

`H(p) = p^4*(1+4q+10q^2) + 20*p^3*q^3 * p^2/(p^2+q^2)`。

保发残差=`收缩保发率 − H(收缩发球得分率)`；破发残差=`收缩破发率 − [1−H(1−收缩接发得分率)]`。每个 scope 输出六种率/残差的 A−B 差（保存、兑现、保发、破发、两个残差），再输出 BP 曝光量 `log1p` 差和、有效历史比赛量与缺失比赛量的 `log1p` 和，共 **10×2=20 列**。所有 `_diff` 交换变号，其余列交换不变。无历史的两人产生中性差，曝光列提示信息量。`attrs` 保存全部先验、版本、时间窗、来源与有效数量。

普通总发球分可能含抢七点，而 `SvGms` 与 BP 只反映普通发球局；因此残差有统计口径和非线性聚合误差，不应解释为纯关键分能力。没有逐点记录，不能还原每场局内点序列或将 BP 压力与球员/对手构成因果分离。场地稀疏、赛事来源质量与先验选择也限制泛化。

## 验证与交接

API：`build_breakpoint_features(targets, inventory, *, cache_dir=DEFAULT_CACHE, raw_rows=None)`，返回原索引与顺序的有限数值 DataFrame。

```sh
.venv/bin/python -m unittest tests.test_breakpoint_features -v
```

6 个测试覆盖手算原始分子/分母与收缩、独立枚举局路径核对 H(p)、T−364/T−21 端点、窗口外/目标技术统计污染、多个目标独立截止、缺失与不可能机会数、同日排列、场地过滤、A/B 交换、未知球员和来源/最终测试保护。独立审阅发现三个机会数嵌套边界，已在首次模型拟合前补足并回归验证；没有改变真实记录的有效数量。

36,421 个开发目标生成 **36,421×20**，耗时约 **1.69 秒**，所有值有限且索引一致。截止内 43,998 场 Tour 历史中，**43,396 场有效，602 场缺失或不一致**；后者对称缺失，不删除预测目标。这里只报告计算检查与覆盖，未计算新模型的 2023 分数。后续保留完整负结果，不依据探索性 2023 表现再修改本块定义。
