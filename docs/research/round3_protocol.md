# 第三轮：更多历史训练比赛与赛制信息

日期：2026-11-24。用户授权继续优化；本轮由多个 AI 辅助 agent 分工实施和独立核验。继续使用 scientific-brainstorming 工作流，出处及已核对的文献见[研究记录](sota_evidence.md)。第一、二轮 2023 结果已经被观察，本轮属于后续探索，不能称为未见验证结果的预注册实验。2024–2025 最终测试仍封存。

## 在本轮评分前确定的问题和反证条件

**H3-Data，假设：** 将训练目标从 2016 年扩展至 2009 年，可通过更多历史样本降低估计方差。替代解释是旧赛季已经过时，增加样本可能稀释较新信号。反证为同一向前验证比赛上无收益，或收益仅来自改变特征/评估行。

**H3-Format，假设：** 已知的三盘两胜/五盘三胜赛制可能改变实力差与获胜概率之间的关系。此假设由协调 agent 在本轮任何评分前补充。反证为控制训练年份后，加入赛制交互项并未降低未来 log loss。

两项假设分别设置对照：2009 起训与 2016 起训交叉比较；赛制特征开/关交叉比较。因此即使总体改进，也不直接把效果归功于“更多数据”或“赛制”。保留线性及平滑非线性模型，以判断效果是否依赖拟合形式。

评价顺序固定：先验证时间截断、原始目标不变和特征一致性，再以训练期向前 log loss 筛选。准确率和计算成本是辅助诊断。历史训练起点固定为 2009，不在看过 2023 后继续寻找最优起点。

## 训练与验证行

从已发布 inventory 中增加符合原条件的 Tour 正赛 2009–2015 目标，共 **17,647 场**。历史仍从 2006 年开始，因此最早新增训练年之前已有历史初始化期。挑战赛、资格赛和测试年份不成为新增训练目标。

| 2010 | 2,549 |
| 2011 | 2,549 |
| 2012 | 2,480 |
| 2013 | 2,496 |
| 2014 | 2,473 |
| 2015 | 2,507 |
| 合计 | 17,647 |

扩展后为 **33,833 训练行 + 2,588 个原样保留的 2023 验证行 = 36,421 行**。原来的 18,774 行逐值、逐列、类型和相对顺序保持一致；输出重新分配 RangeIndex。新增目标按照真实赛季、真实日期和比赛 ID 排序，不把旧年份伪装成 2016 年。

`build_expanded_targets(original, inventory)` 将 A/B 按球员 ID 字典序规范化，必要时同步交换姓名、排名及标签。新增 `match_id` 去掉 inventory 的 `tour:` 前缀；日期使用 ISO 格式；新增行 `split=train`。四项原始预测量保持原定义：

- `log_rank_diff = log(rank_B) - log(rank_A)`。
- `overall_rate_diff`：T−90 至 T−21（均含端点）的平滑整体胜率差。
- `surface_rate_diff`：T−364 至 T−21（均含端点）的同场地平滑胜率差。
- `h2h_rate_diff`：2006 年起截至 T−21 的交手优势 `2*(A胜场+1)/(交手场数+2)-1`。

个人平滑胜率仍为 `(胜场+1)/(场数+2)`。扩展函数还独立重算原来全部 18,774 行的这四项预测量，以绝对误差不超过 `1e-12` 校验，并核对 ID、日期、排名、场地、标签和 split；任何不一致都会停止。

## 特征与已验证的赛制来源

`build_expanded_features(targets, inventory)` 返回 **202 列**。前 198 列的顺序、定义与第二轮完全一致；后面新增四列：

| 列 | 定义 | 球员交换 |
| --- | --- | --- |
| `format_best_of_five` | 原始赛前 `best_of` 为 5 的标记 | 不变 |
| `format_log_rank_diff` | 该标记 × 原排名差特征 | 变号 |
| `format_elo_diff` | 该标记 × `elo_k32_diff` | 变号 |
| `format_points_diff` | 该标记 × 一年整体发球/接发胜率差之和 | 变号 |

实际使用固定原始年度文件的 **`best_of` 元数据**，按比赛 ID 和赛季连接；不通过赛果或已经打了几盘推断赛制。缺失值、非 3/5 值或目标漏连均停止。

在任何第三轮评分前，已逐行核验全部 36,421 场的原始字段：大满贯 `G/5` 共 **7,163** 场，`250/3` 共 **15,784**，`500/3` 共 **5,661**，`M/3` 共 **7,813**；大满贯与五盘三胜映射没有例外。实现仍读取实际 `best_of`，不依赖将来一定成立的级别映射。全年计数是数据核验，尚不是预测效果证据。

四个历史特征 builder 新增显式 `first_target_season` 关键字。默认仍为 2016；仅允许选择 2009–2016 的起始年，截止始终是 2023。旧调用的保护行为不变，测试年份不能通过调小起点进入。本轮特征定义、先验、历史来源、T−21 截断和所有动态更新参数均不调整。

## 评分前冻结的比较与选择规则

训练脚本 `scripts/train_round3.py` 定义 **32 个候选配置**：两种起始年 × 两种赛制条件 × 每组四个线性和四个平滑模型配置。线性配置的 C 为 0.003/0.01，并比较无额外样本衰减与固定五年半衰期；平滑配置复用第二轮固定网格，不根据本轮 2023 结果扩大网格。

1. 维持 2020、2021、2022 向前验证折及原有 21 天边界隔离规则；每个起始年条件的验证行完全相同。
2. 只按 2020–2021 的结果选出一个全局候选，同时保留各训练起点/模型/赛制条件的代表结果。
3. 用该候选的 2022 预测与第一轮同样只用 2020–2021 选择的参考集成比较。只有 log loss 至少改善 **0.001** 才升级流程；否则保留第一轮推荐。
4. 确定是否升级后，才使用全部 2020–2022 训练期折选择最终配置，然后拟合冻结模型，最后输出探索性的 2023 对比。
5. 保留候选、概率、源文件哈希、旧结果对照与失败/无收益方案；不因某个 2023 数字更好而重写采用规则。

旧赛季更多但仍有时间漂移；2022 也参与过此前流程开发，因此它是操作性升级门槛，不能取代未开启最终测试。后续报告应同时保留这一限制和全部尝试次数。
