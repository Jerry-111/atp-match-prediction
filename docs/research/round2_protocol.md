# 第二轮实验：在第一轮之后继续优化

日期：2026-11-24。用户明确要求继续实验，并允许多个 agent 并行工作。
本轮继续应用 scientific-brainstorming 工作流：各实现者先独立记录候选、假设和反证条件，再实现和交叉审阅。
这些角色均为 AI 辅助，不代表独立的人类专家；技能出处见第一轮研究记录。

## 已知信息与边界

我们已看到第一轮 2023 验证结果：排名 log loss 0.62980，原先冻结的集成 0.61153，扩展线性模型 0.61056。
因此本轮是**后续探索**，不得称为尚未观察验证集的预注册实验。
2024–2025 最终测试继续封存。比赛范围、18774 个开发目标、A/B 定义和 T−21 信息截止保持不变。
不改变或覆盖第一轮搜索记录、概率和模型选择。

## 独立候选方向（尚不是结果）

- R2-D：不确定性随休赛增长的动态实力评分，用新选手/稀疏场地的可靠性补充固定 Elo。
- R2-P：对手调整后的动态发球/接发能力，区别技术水平、对手构成和时间衰减。
- R2-L：强正则的平滑非线性模型，允许实力差的饱和效应和场地/历史可靠性交互。
- R2-C：使用上述信息的紧凑线性/树模型，以及同一时间验证规则下的组合。

评价先过信息泄漏和球员交换对称性检查，再以向前验证的平均 log loss 为主。
准确率、年度一致性、概率校准与实现复杂度作为诊断，不为漂亮的验证数字随意更换主要指标。
反证包括：新方法只降低训练损失；只在一个年份改善；移除新增信号后结果不变；未来数据污染早期特征。

## 在查看本轮 2023 评分前确定的筛选规则

1. 仍使用 2020、2021、2022 向前折，每折拟合只用更早且距预测起点至少21天的训练行。
2. 每一新模型家族的候选配置在训练期折内比较；所有尝试写入注册表和 CV 结果。
3. 选择2020–2021内最优的各家族配置，拟合非负凸集成权重，分别生成2022的单模型和集成预测。
4. 对照第一轮同样只用2020–2021选定的集成流程在2022的预测。仅当新流程在2022的log loss至少减少0.001时，才替换上一轮推荐；否则保留上一轮。
5. 决定采用的流程后，在2020–2022全部折重选配置和权重，随后固定，才计算本轮2023对照。
6. 即使新候选2023分数更低，也不静默改写上一步的推荐。清楚区分训练期筛选、选择流程用的2022、探索性2023和未开的最终测试。
7. 输出原推荐/原线性/排名与新候选在同一批2588场上的指标、配对日期块区间、失败或无增益的方法，以及可重载的模型文件。

第一轮的家族 OOF 概率可以作为缓存复用，但必须核对比赛ID、标签、来源哈希和折设置。它们的预测每行由更早的训练数据产生。
模型或权重在这些OOF行上再拟合后的损失是元训练损失，不能作为额外独立验证。
最终测试前仍需独立核验；多轮探索的选择不确定性不能靠普通配对区间完全消除。
