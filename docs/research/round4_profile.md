# 第四轮：年龄、排名积分及赛前快照审计

记录日期：2026-11-25。代码为 `scripts/paper_profile_features.py`，当前属性版本为 **3**。本记录只涉及方法和数据质量，没有用第四轮2023指标选择修复方式；2024–2025最终测试保持关闭。

## 论文依据与项目改编

年龄变换直接核对了 Buhamra 与 Groll 的作者预印本 [arXiv:2502.01613v2，第2节](https://arxiv.org/html/2502.01613v2)：`abs(age-30)`，以及到区间 `[28,32]` 的距离 `max(28-age, 0, age-32)`。常规年龄和 ATP 排名积分也是该文列出的赛前协变量。相关期刊研究链接为 [DOI:10.1177/22150218251338954](https://doi.org/10.1177/22150218251338954)；实际核对变换的文本版本是上述 v2，代码 attrs 同时保留这两个引用，不将两者认定为同一文章的不同版本。

本项目额外使用 `log1p(points)`、积分除以1000、年龄和对数积分的均值，以及缺失指标。这些是项目的表示与缺失处理，不能当作论文整套模型的复现。全部差值遵循项目 A−B 方向；缺失年龄固定填30、缺失积分固定填0，同时保留指标，不从验证数据估计填充值。

## 覆盖全部开发目标的快照扫描

对第三轮冻结开发目标的 **36,421场**2009–2023比赛，连接 SHA-256 固定的年度原始文件，只扫描年龄与排名积分字段。按 `(season, tourney_id, player_id)` 分组，共 **38,055个球员—赛事组合**。没有仅检查已知异常赛事，也没有打开2024–2025年度文件。两个 agent 独立扫描得到相同结果。

积分在同一球员同一赛事内出现不同值的组合只有两个：

| 赛事 | 球员ID | 原始积分取值 |
| --- | --- | --- |
| 2019-418 Washington | KE17 | 1000、975 |
| 2019-418 Washington | GB93 | 418、393 |

年龄变化也仅出现在同一赛事，共八个组合：

| 球员ID | 原始年龄取值 |
| --- | --- |
| KE17 | 24.249、24.255 |
| G967 | 30.031、30.037 |
| GB93 | 28.953、28.958 |
| E831 | 24.548、24.553 |
| PD31 | 30.218、30.223 |
| C977 | 30.825、30.831 |
| MM58 | 23.455、23.461 |
| TE51 | 20.956、20.961 |

这些源记录混用了2019-07-27与2019-07-29日期。年龄差与两天的日期差一致，但本审计没有据此推断生日或年龄计算约定。积分变化同样不能据此直接定性为比赛结果泄漏：已证实的问题是，同一赛事的赛前属性使用了不一致的时间快照。

扫描能识别同一赛事内的数值变化，**不能证明所有未变化的原始字段均具有完备的赛前可用性记录**。因此不能把本次审计表述为对所有源数据时间性的绝对保证。

## 修复策略与确切影响

已有 `scripts/model_event_metadata.py` 中的 `EVENT_METADATA` / `RANKS_BY_WEEK` 提供官方开赛日期及严格早于开赛的周排名纠正，并注明固定排名档案来源、玩家映射和哈希。Washington统一开赛日为2019-07-29，采用2019-07-22排名。**这份现有可信纠正只包含排名，不包含已核验的积分或年龄快照。**因此没有把原始1000/418猜作可替换的正式积分，也没有从年龄差倒推生日。

对所有 `EVENT_METADATA` 审计赛事，profile 分支将双方年龄和积分一并标为缺失，使用固定填充和既有缺失指标。规则按赛事成员身份固定，不依赖赢家、轮次、标签、模型得分或原始属性的大小；原始字典不被修改。常规赛事继续使用其原始赛前属性。

实际重新构建 **36,421×11** 特征后，attrs 确认开发集中只有 `2019-418` 受到影响：**47场比赛、94个年龄出场记录、94个积分出场记录**。重建后的年龄缺失总数和积分缺失总数均为94，说明当前开发目标无其他缺失。代码同时保存遮蔽策略、审计来源、事件列表及两个确切计数，便于训练登记文件追踪。

另外两个2024审计周以及三个2024事件名称仅作为既有元数据存在；本构建器拒绝2024–2025目标，未读取这些年份的比赛结果。此次修改没有改动原始目标、排名纠正、历史评分或前三轮冻结产物。

回归测试要求 Washington 早轮与晚轮原始年龄/积分同时变化时，输出仍完全一致；同时验证交换对称、固定缺失指标、输入不被修改，以及非审计赛事的数据和空遮蔽记录保持正确。
