# 独立附加实验：加入实际赛前市场信息

2026-11-25，首次新市场2023评分之前记录。用户允许继续向70%准确率优化；此实验是额外信息条件，**不替换T−21主实验，也不能称作仅靠原有历史特征的算法增益**。

数据由[Valuebetennis](https://www.valuebetennis.com/en/donnees.htm)按CC BY4.0发布，仅下载2021、2022、2023三个单年文件。该站定义开盘报价和赛前最后报价；没有逐条报价采集时间，因此依据其公开说明，不能独立证明每条价格在指定时刻已公开。实际比赛的赛前价格通常晚于目标表的赛事开赛周。匹配使用姓名、球员标识、赛事、场地、日期等身份信息，不用胜者、比分、时长。数据审计、哈希和覆盖另见[市场来源记录](round5_market.md)。

## 固定输入与覆盖规则

- 可训练市场模型只使用**开盘**双边赔率：2021的收盘字段全空，因此收盘只能作为单独原始基准，不能与完整跨年训练混同。
- 去水概率为`(1/odds_A)/(1/odds_A+1/odds_B)`，赔率必须双边有效；全量目标均保留，任何无匹配或无有效报价的行，概率**精确回退到第四轮冻结模型**。不删缺失行来提高整体准确率。
- 历史模型输入固定第四轮`add_age_spline_C0.01`：2021/2022使用真实向前OOF概率，2023使用其冻结模型预测；不改为在这些训练行拟合过的概率，也不根据第五轮2023成绩改换底模。
- 阈值固定0.5，模型无截距并保持A/B对称。开盘与收盘单列覆盖率、缺失数和全量分数。重叠有报价样本的结果只能作为补充。

## 20个固定候选与时间选择

候选含原模型、原始去水开盘概率、权重0.25/0.5/0.75的概率和logit融合（共8项），再加三种有明确输入的logistic校准/融合，各C=0.01/0.1/1/10（12项）。三种输入分别为市场logit；市场和历史logit；两者及少量固定的置信度/报价margin交互。未引入目标比赛技术统计、源预测结果或身份编码。

1. **2021年下半年**为第一选择折（赛事日期≥2021-07-01），有拟合需求的模型仅用该折最早日期−21之前的2021记录。无拟合候选仍在同一完整选择折上比较。
2. 用该折accuracy最高选择，log loss不超过第四轮参考+0.005，平局按较低loss和固定名称。2021样本不足完整年度向前训练，因而不虚构2020市场资料。
3. **2022全量目标**为升级检查；校准模型仅用2021训练，固定权重不变。要求相对第四轮同批概率至少提升0.005 accuracy且loss最多恶化0.005，才采用市场推荐。此门槛与主实验独立；2022此前已见，依然是探索性检查。
4. 在2021H2+2022的真实时间外预测上重选固定候选；校准模型最终仅用2021–2022有效开盘记录及底模OOF输入拟合。无论门槛是否通过，都保留探索性候选；只有通过才替代此信息条件下的推荐。冻结后才评分同一2,588场2023比赛。
5. 收盘原始概率基准不参与模型选择。2024–2025继续封存，不下载、不评分。

报告与原模型同一全量分母的accuracy、正确数、log loss、Brier、70%剩余差距、日期块改善区间和相对原始市场概率的增量。若达到70%，明确“使用赛前市场信息、在已反复使用的2023样本上的探索结果”；不称为纯历史模型达到70%，不声称超过市场或独立最终测试。

## 追加记录：收盘信息的固定融合控制

主实验和20项开盘实验评分完成后，已看到纯历史探索组合66.27%、开盘选中流程66.73%、收盘原始基准67.70%。据此追加**16项明确自适应的探索控制**：R4固定底模/R5 pooled固定探索组合分别与closing按概率或logit融合，市场权重仅0.25/0.5/0.75，另保留双方单独基准。只用2022的同口径预测选择，accuracy优先、loss≤R4+0.005；在新2023融合评分前写冻结选择。没有独立升级门槛，不据此替换原推荐，也不把重复已见2023说成新验证。缺closing的111场精确回退到各自底模；全部2588场保留。单独输出`results/round5/closing_blend`，保留之前全部结果。
