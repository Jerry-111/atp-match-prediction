# 第六轮：新增历史信息与跨级别监督迁移

2026-11-27，用户授权继续优化，目标仍向全量70%推进。前三位AI协作者先独立提出候选，协调者随后合并、质疑并分工。使用scientific-brainstorming及其idea_evaluation/responsible_ai参考；归属沿用[sota_evidence.md](sota_evidence.md)。没有真实人类专家投票，也不把多个AI建议视为独立实证。原来的2023结果和2022选择都已反复查看，本轮全为探索性，2024–2025继续封存。

焦点：在保持2588场2023完赛目标、固定0.5阈值与历史T−21截止下，新增可核验信息或新的监督来源能否改善已有模型？不缩小分母，不换最终测试集，不修改既有真值以提高分数。排名为原任务允许的已知赛前元数据；所有新历史结果只截至T−21。所有旧产物保留，主正式参考仍是第四轮年龄样条。

## 主实验固定规则

旧第五轮275项核心+年龄+跨级别+风格作为匹配起点。比较起点、加扩展历史、加排名轨迹、加关键分、三者全加五组；每组logistic与odd-spline，C=.003/.01/.03，half-life=3，共30项。另用全部原326项加新块的linear/spline C=.01两项，以及全部新块的CatBoost depth4/6、600轮、固定正则20两项，共34项拟合配置。特征名和确切参数写入JSON后才训练。

2020/2021/2022向前折与各折21日purge沿用。复用第四轮正式模型的既有OOF概率，不用样本内预测代替。第五轮冻结探索混合与第五轮最低观察loss模型只报告固定对照，不参加早期选择，避免把其pooled权重或已见2023最佳身份带入本轮gate。按第五轮函数：早期2020–2021准确率优先且loss≤正式参考+.005，在有限非负和为1网格中选方法混合；2022准确率提升至少.005且loss护栏通过才能升级。随后pooled2020–2022重选并冻结2023比较；失败则保留正式参考。第四轮参考本身也是既往筛选的模型，门槛不是独立验证或显著性检验。所有家族和负结果均报告。

## 监督迁移分支

辅助目标仅用2009–2022的Challenger/qualifying；源数据可见75,261条辅助监督记录，原Tour训练目标33,833不变。共享紧凑特征，辅助权重0/.1/.3/1，2种logistic正则及一种样条，共12拟合配置，配固定权重的旧模型融合控制。权重0是匹配的Tour-only对照；标准化/变换只从实际拟合行学习。全局样本权重总量归一到Tour行数，避免仅因样本增加改变有效L2。按同样早期选择、2022升级门槛和loss护栏，2023评分前冻结。详见单独迁移协议与机器注册表。

## 一手来源与检索边界

本轮先生成再检索，检索日期2026-11-27。查询包含tennis match prediction break points、dynamic paired comparison、cross-domain learning tennis与nontransitive matchup；不是系统综述，不声称文献空白。

- [Klaassen与Magnus 2001作者PDF](https://janmagnus.nl/papers/JRM057.pdf)：网球点独立同分布存在小偏离；不能据此断言BP残差可预测赛前胜负。
- [Gollub 2021](https://journals.sagepub.com/doi/pdf/10.3233/JSA-200345)：讨论serve预测的样本量和赛程强度偏差；改善serve预测不等于本项目准确率提升。
- [Chen与Joachims 2016作者PDF](https://www.cs.cornell.edu/~tj/publications/chen_joachims_16a.pdf)：skew-symmetric对位的思想来源，但§4.4网球实验没有accuracy提升，是暂缓R3的反证。
- [Ben-David等2010](https://link.springer.com/article/10.1007/s10994-009-5152-4)：源/目标域学习依赖域差异与共享假设；不直接证明Challenger迁移有效。
- [Ingram 2019](https://arxiv.org/abs/1902.07378)：GP动态成对模型可加入surface，在其2018样本改善log loss；与本轮不同年份、任务和算力，不能移植headline结果。

追加执行差异与结论时保留以上假设，不根据2023排序改写选择规则。
