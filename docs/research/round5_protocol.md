# 第五轮：向全量70%准确率推进

2026-11-25。用户在第四轮结果后要求“继续优化尽量到70%”。这是将本轮选择目标明确改为**准确率优先**的授权；原概率预测目标、第四轮模型及所有既有结果继续保留。协调者和三个独立agent使用scientific-brainstorming流程先提出想法，再查来源、交叉质疑和实施。技能归属沿用[证据记录](sota_evidence.md)。这是AI辅助方法探索，没有真实独立专家小组或未见数据验证。

## 焦点、度量和边界

仍预测完整2,588场2023 Tour/大满贯完赛目标，不改变资格、筛选或分母，不以只选高置信比赛或只选五盘赛声称达到70%。70%至少需要1,812场正确，较现推荐1,696多116场，较既有最好观察值1,705多107场。固定阈值0.5、固定A/B方向；所有模型必须满足球员交换后的互补概率。准确率是本轮主目标，log loss和Brier同时报告，避免把更差的概率估计藏起来。

主实验保持2009–2022的33,833个拟合目标，原始259项输入、T−21历史截止、2020/2021/2022向前折，以及2024–2025最终测试封存。所有后续2023结果仍是探索性。旧年份的重复使用无法通过重新命名验证集消除。

## 主实验候选和选择规则（新评分前记录）

1. 比较旧历史+年龄、加跨级别、加风格、两者都加；固定线性/样条正则及少量近期权重控制。补充26项不同学习损失/核表示，少量CatBoost/HGB及全论文输入控制。完整JSON登记在任何拟合前写入。
2. 保存原第四轮概率推荐、第三轮最高已观察准确率线性对照和第四轮最低已观察loss对照；它们的旧OOF和冻结模型均不改变。选择时参考损失及门槛基准均使用**当前实际冻结的第四轮推荐**，不退回较弱的排名或第一轮模型。
3. 2020–2021先按accuracy最大选择候选，同accuracy以更低log loss、稳定名称打破平局；只允许log loss不超过参考+0.005的候选。按同规则每个方法家族挑一个，再取至多四个，枚举步长0.1的非负和为1权重；混合和单模型共同竞争。所有权重只用早期OOF，不调0.5阈值。
4. 在2022，早期选中流程必须比当前第四轮参考提高至少**0.005准确率（0.5个百分点）**，且log loss不恶化超过0.005，才升级本轮准确率推荐；否则保留旧推荐。该门槛不是显著性检验。随后用全部2020–2022重选候选/权重并锁定2023比较；只有通过门槛才作为推荐，未通过时仅作明确标记的探索比较。全部家族和失败分支均保存。
5. 额外报告2023准确率改善的日期块配对区间、正确数变化、达到70%还差多少场；区间不覆盖全部搜索偏差或跨日期重复球员依赖。旧概率推荐的身份不会被悄悄改写。

## 方法证据与额外信息条件

分类损失的选择参考Bartlett、Jordan与McAuliffe（2006）的[原论文](https://sites.stat.washington.edu/courses/stat527/s14/readings/Bartlett_etal_JASA_2006.pdf)：合适的logistic和hinge均可有分类一致性，不能声称换损失天然更准。随机傅里叶表示依据Rahimi与Recht（2007）的[原论文](https://papers.neurips.cc/paper_files/paper/2007/file/013a006f03dbc5392effeb8f18fda755-Paper.pdf)。实现和适配另记。

Kovalchik（2016）的[同类模型比较](https://vuir.vu.edu.au/34652/1/jqas-2015-0059.pdf)和Wilkens（2021）的[大样本比较](https://journals.sagepub.com/doi/full/10.3233/JSA-200463)使市场信息值得作为参照，但不同年份/总体的70%不是本仓库可直接继承的指标。

外部数据检索记录：tennis-data.co.uk原站、说明及单年文件均返回403；tennisdata.app公开导出页要求安全检查，未绕过。另找到[Valuebetennis公开数据](https://www.valuebetennis.com/en/donnees.htm)，提供2021–2023单年文件、CC BY4.0授权、开盘报价及赛前最后报价定义。仅在完整来源/哈希、无标签身份匹配、双边价格有效性与覆盖审计通过后启动独立分支；不下载最终测试年份。其实际比赛前市场信息晚于赛事开始周，不能与原T−21信息集混为一谈。原始比赛结果/比分只可用于匹配后的独立一致性审核，不能用来挑匹配或作为预测变量。

本记录会追加执行差异和负面发现，不在见到结果后改写原假设。
