# ATP 男单赛前预测项目计划

**预测目标**　给定两位球员及比赛场地，用赛事开始时可获得的信息，估计球员 A 赢下这场男单比赛的概率。范围为双方正常完赛的 ATP 巡回赛和大满贯正赛。若 A 的预测胜率为 65%，B 的预测胜率就是 35%。

**主研究问题**　赛前可以多准确地预测 ATP 男单一场比赛的获胜概率？在世界排名之外，近期整体状态、同场地表现和双方历史交手，各自提供多少额外的预测信息？

**英文题目**　*Predicting ATP Match Win Probabilities: What Does Match History Add Beyond Rankings?*

老师在 Assignment 2 课件第 10–13 页要求说明特征选择依据，比较不同的特征表示和基准，解释哪些信息有预测价值。第 16–20 页用餐厅评分举例，将顾客历史、时间和地理位置用于同一预测任务，再检验位置信息的贡献。第 32 页的往届漫画标题项目比较了词频、TF-IDF 和降维表示。下面的四组网球特征和验证方法是本组的设计。[Assignment 2 原版课件](https://drive.google.com/file/d/1CwsbNGf98gcQRfw2FPCpoRAoJoqlTbcQ/view) · [正式作业要求](https://docs.google.com/document/d/1w_g-yEtn9lvmXIXQWjQoS51FugM_Mx-ACh0-EZcHWR8/edit)

| 相关研究 | 用一页讲已有研究用了哪些比赛、怎么预测、发现了什么，再对照本组结果。Kovalchik 可用来解释为何选择排名作基准，Vaughan Williams 等人的研究可用来讨论按场地衡量实力的价值。对照 Elo 与本组模型的表现时，说明对手实力、比赛范围和评估年份对比较的影响。 |

## 综合模型与特征选择

每场比赛只有一个目标 `a_won`。所有候选模型使用同一批 2016–2022 年训练正赛和 2023 年验证正赛。设 T 为本届赛事开赛日，历史只纳入已经清洗的巡回赛和四大满贯男单正赛，最近可用日期为 T−21 天。这个保守间隔沿用原实验的赛事周口径。

| 特征组 | 输入如何构造 | 这组信息回答什么 |
| --- | --- | --- |
| 世界排名（固定基准） | 使用已有的 `log_rank_diff = ln(rank_B) − ln(rank_A)` | 谁的整体排名更高？ |
| 近期整体状态 | 在 T−90 至 T−21 天（含端点）跨场地算双方平滑胜率，A 减 B，记为 `overall_rate_diff` | 谁在最近可观察的比赛中表现更好？ |
| 同场地战绩 | 用现有 `surface_rate_diff`，取 T−364 至 T−21 天（含端点）在本场同类场地的胜率差 | 谁在这类场地上表现更好？ |
| 历史交手（H2H） | 从 2006 赛季取截至 T−21 天双方在所有场地的直接交手。令 `h2h_rate_diff = 2 × (A 对 B 的胜场 + 1) / (交手场数 + 2) − 1` | 这对球员过去交手是否长期偏向一方？ |

个人平滑胜率统一取 `(胜场 + 1) / (场数 + 2)`。零交手时 H2H 优势为 0，两人仍可通过排名和其他表现得到不同的胜率。按上述长窗口，16,186 场训练比赛中有 7,597 场（46.9%）有直接交手史。若只回看与场地特征相同的 52 周，则只有 3,570 场（22.1%）。长窗口提高覆盖，也会让早年交手进入特征；验证集检验其实际价值。

1. **基准。** 总选排名高者给出胜者判断。只用排名差的逻辑回归给出概率，是比较 log loss 的起点。另从 2006 年的合格正赛开始累积跨场地 Elo，按 T−21 截止取双方的评分，在同一批比赛上报告 Elo 的概率预测。实现时记录初始评分、更新系数和同一赛事日期内的处理顺序，先在训练期确定这些设置。
2. **选择特征。** 固定排名，另外三组各有「用」或「不用」两种选择，共八种组合，已含排名基准模型和四组全用的模型。各组合使用相同的正则化逻辑回归协议；如要选择正则强度，先在训练年份内按时间向前验证。标准化参数只从训练数据估计。
3. **比较贡献。** 以 2023 年平均 log loss 选组合；同分取特征更少者。同时展示完整模型分别移去整体状态、场地、H2H 后的分数差。这能量化给定其他输入时的预测增量。特征相关时，移去某组影响小也可能是其他组携带了类似信息。
4. **最终评估。** 锁定设置后，再对 2024–2025 的相同比赛比较排名基准、Elo、完整模型和选中的模型（相同则合并）。报告分年及合并的 log loss、准确率和样本量。画校准图时，把预测胜率相近的比赛分组，标出各组样本数，比较平均预测胜率与 A 的实际胜率。用这张图解释胜率的可信程度。允许某些特征没有帮助，结论以测试表现为准。

**可选扩展。** 若主实验完成后还有时间，只加一组历史技术统计：从 T−364 至 T−21 的合格正赛跨场地汇总每名球员的发球、接发得分与总机会数，形成两项 A/B 差值。比较四组模型与四组加技术统计，保持验证比赛相同。先用训练数据定好低样本时的平滑方法。

### 2026-11-24 已授权的强模型扩展

用户要求尽可能提升预测性能，因此将上面的单项可选扩展扩大为一项有完整记录的模型比较。保留原八组逻辑回归及同一批目标比赛，同时加入多尺度整体/场地 Elo、对手强度调整后的状态、历史发球/接发统计、梯度提升及时间外预测集成。没有改变完赛筛选、T−21 截止或 2024–2025 最终测试封存规则。

所有超参数先在训练期内以 2020、2021、2022 年向前验证选择。集成的设置与权重先用 2020–2021 年决定，以 2022 年检查是否采用集成流程，再用全部训练期折重拟合；推荐的强模型在查看新增 2023 年评分前锁定。原八组特征仍依照原计划以 2023 年选择，必须与训练期选出的强模型区分。比较所有候选的结果，不能只展示最好的一行。完整搜索、模型文件、概率输出和复跑命令见[建模协议](modeling.md)；研究候选、证据和未实施方向见[研究记录](research/sota_evidence.md)。本次结果只能支持本项目内的验证结论；SOTA 声明还需要相同口径的竞争模型和独立最终测试。

### 用户授权继续实验：第二、三轮

第一轮结果之后，用户要求继续优化并使用多个agent并行实验。因此后续2023分数明确记为**已重复使用验证集上的探索结果**。继续封存2024–2025，不追溯称为未见数据测试，也不覆盖第一轮冻结产物。

第二轮比较动态Glicko实力、对手调整的发接发能力及平滑非线性等37个新配置；第三轮用32个配置交叉比较2009/2016起始训练年份、加/不加已知赛制、线性/样条及正则/时间衰减。第三轮扩展的是训练样本，验证目标仍为原来的2588场；原始198项特征在原目标行上必须复现一致，新增赛制只使用赛前已知字段。

两轮均先在2020–2021选择候选，再在2022与第一轮相应早期选定的集成流程比较。至少减少0.001 log loss才采用新流程；未达到则保留旧推荐。这个门槛是实用选择规则，不等于显著性检验。完整假设、记录和复跑见[第二轮](round2.md)、[第三轮协议](research/round3_protocol.md)。

### 2026-11-25 用户授权参考论文继续优化：第四轮

核验原论文公式后，实现比分加权WElo、对手网络Perron中心性、逐分到整场概率递推，以及年龄形状和ATP排名积分。仍使用相同33,833个训练目标、2,588个2023目标，保留全部202项第三轮输入。51个配置包括单组添加、全部加入、逐组删除、年龄/积分拆分、紧凑模型、树模型和原始公式概率基准。论文的样本、日期粒度和计分规则与本项目不同之处必须明确记录，不能直接比较论文准确率。

### 第五轮：用户要求向70%准确率推进

本轮用户明确要求“继续优化尽量到70%”，因此新选择流程以准确率优先，同时要求log loss不比当前参考恶化超过0.005，固定0.5阈值与全部2588场目标。增添跨级别比赛历史和技术风格共67项输入，比较75项新历史配置及有限权重混合；2020–2021选流程，2022至少增加0.5个百分点才升级。实际只提高0.198个百分点，正式推荐保留第四轮。新探索集成2023为66.27%，未达到70%。[固定协议和结果](../results/round5/overview.md)

为检验新信息条件，另比较20项开盘市场模型，并在见过其2023结果后明确追加16项收盘固定融合控制。它们使用供应方声明的实际赛前报价，晚于原赛事周T−21信息集；必须单列。对应冻结开盘方案66.73%、追加收盘融合67.27%、收盘原始市场基准67.70%，均未到70%，也不证明自建模型超过市场。没有剔除缺赔率或难预测比赛；2024–2025继续封存。来源、无结果字段匹配、缺失回退和自适应追加记录见[市场协议](research/round5_market_protocol.md)。

### 第六轮：新增信息与监督迁移的负面结果

2026-11-27继续优化，保持T−21与全量2588场目标。补入4291场官方赛事历史、历史排名轨迹、关键分/保发残差，共57项新输入及34项配置。开发期升级门槛仍未通过，2023选中探索组合为65.42%，低于第五轮66.27%。独立迁移分支加入最多75261场低级别监督目标，比较12项配置及36项固定混合；选中方案反而不使用辅助样本，2023为65.77%。看到主实验失败后追加的单一最低CV-loss对照为66.07% / 0.60755，明确为自适应探索，也不替换原推荐。
